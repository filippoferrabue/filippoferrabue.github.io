Projects

University Student Information System

MIPS Assembly

A complete student records manager written entirely in MIPS-32 assembly for the MARS simulator: 17 operations covering insertion, search, sorting, credit-weighted averages and reporting, over a database of up to 100 students with 20 exams each.

The interesting constraint is that MIPS offers no structs and no dynamic allocation, so every data structure had to be built from raw memory. Student records live in parallel arrays sharing one physical index; transcripts live in a 2D matrix flattened into 2000 sequential slots, with each address computed at runtime. Deletion clears an active flag rather than shifting memory, keeping removal at O(1).

Personal health data pipeline

Python · Supabase

An end-to-end pipeline that turns the raw output of my Amazfit watch into something I can actually ask questions of. Apple Shortcuts pull the metrics out of HealthKit, Supabase stores them, and the Claude API runs the analysis against my own history rather than a generic population baseline.

The point of the project is the plumbing: getting data out of a closed ecosystem, keeping it consistent across days and devices, and shaping it so the analysis is worth reading. Ongoing.
